# Our Story So Far — Anniversary Website ♥

A deeply personal, romantic scrapbook-styled interactive anniversary website for **Aryaveer & Bhoomika**, built with pure HTML, CSS, and Vanilla JavaScript.

## 🌟 Features
- **Live Counter:** Real-time counter displaying days, hours, minutes, and seconds since 29th July 2025.
- **Interactive Milestones:** Milestone cards celebrating key moments.
- **Scrapbook Gallery (167 Photos):** Masonry scrapbook photo grid with custom handwritten captions for all 167 photos + full lightbox modal preview.
- **Moons That Complete Each Other:** Scroll-triggered SVG crescent moon merge animation with personalized romantic text.
- **Interactive Love Letter:** Realistic CSS envelope that unseals on click to reveal a scrollable love letter.
- **Two-Song Floating Music Player:** Bottom-right mini-player with Play/Pause, Next/Skip, track counter (`1/2`), and auto-advance playback.
- **Zero Build Tools / Zero Dependencies:** Pure vanilla web standards — works by double-clicking `index.html` or deploying directly to GitHub Pages.

---

## 🚀 How to Deploy to GitHub Pages (3 Easy Steps)

1. **Create a GitHub Repository & Push Code**
   - Go to [GitHub](https://github.com) and create a new repository (e.g. `our-story-so-far`).
   - Push or upload all files from this workspace directly to the root of your repository (`index.html` MUST sit at the root).

2. **Enable GitHub Pages**
   - Go to your repository **Settings** → **Pages** (in the left sidebar).
   - Under **Source**, select **Deploy from a branch**.
   - Choose `main` (or `master`) branch and `/ (root)` folder, then click **Save**.

3. **View Your Live Site**
   - After 1–2 minutes, your live site URL will be ready at:  
     `https://<your-username>.github.io/<repository-name>/`

## 🔒 File Safety & Hosting Notes
- All photo filenames and audio filenames are percent-encoded (`encodeURIComponent`) and set with relative paths (`assets/...`) so they load reliably on case-sensitive hosting servers like GitHub Pages.
